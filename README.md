# קטלוג ספרים - האיל הקורא 📚

מערכת מקוונת לניהול קטלוג ספרים משומשים, פועלת ישירות בדפדפן עם שמירה מקומית.

## 🌐 הדגמה חיה

**האתר:** https://gitdawn.github.io/ayal-kore/

## ✨ תכונות עיקריות

- 📥 **העלאת קטלוג דאנאלוג** - תמיכה בקבצי Excel עד 300,000 שורות
- 🔍 **חיפוש מהיר** - חיפוש לפי שם, מחבר, נושא, דאנאקוד, ברקוד ועוד
- ✏️ **עריכת פרטים נוספים** - הוספת מידע שלא קיים בקטלוג המקורי
- 📊 **ניהול מלאי** - מעקב אחר כמויות לפי מצב הספר (חדש/טוב/בינוני)
- 💎 **עותקים מיוחדים** - ניהול ספרים נדירים עם מחיר ייחודי
- 💾 **שמירה מקומית** - כל הנתונים נשמרים במחשב שלך (IndexedDB)
- 📤 **ייצוא וגיבוי** - ייצוא הנתונים לקובץ JSON

## 🚀 התחלה מהירה

1. פתח את [האתר](https://gitdawn.github.io/ayal-kore/)
2. העלה קובץ Excel של דאנאלוג (או השתמש ב[קובץ הדוגמה](דוגמה_קטלוג_להעלאה.xlsx))
3. חפש ספרים והתחל לערוך!

## 🛠️ טכנולוגיות

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **אחסון:** IndexedDB (מקומי בדפדפן)
- **Excel Processing:** SheetJS (xlsx.js)
- **Hosting:** GitHub Pages

## 📊 שדות מקטלוג דאנאלוג

המערכת תומכת בכל שדות קטלוג דאנאלוג:
- דאנאקוד, שם, מחבר, נושא
- ת.מחלקה, מחיר, ברקוד
- תאריכים (פתיחה, עדכון, מהדורה ראשונה)
- ועוד...

## 💡 שדות נוספים שניתן להוסיף

- כותרת משנה
- מתרגם
- הוצאה לאור
- שנה
- מספר עמודים
- כריכה
- גודל
- שם סדרה ומספר בסדרה

## ⚠️ הערות חשובות

- ✅ הנתונים נשמרים **במחשב המקומי** בלבד
- ✅ אין צורך בשרת או בסיס נתונים חיצוני
- ⚠️ **חובה לגבות את הנתונים** באופן קבוע (ייצוא ל-JSON)
- ❌ אל תנקה Cache/Storage של הדפדפן

## 🔄 עדכונים אחרונים

- **ינואר 2026:**
  - תמיכה ב-300,000 שורות (במקום 50,000)

  - הרחבת רוחב הקונטיינר ל-95% מהמסך
  - הוספת כפתור "ערוך" בתחילת כל שורה
